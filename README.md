# 🔥 KUDETA-WEB Bot by ZAAX

Bot WhatsApp full kontrol dengan sistem pairing, VIP access, dan work report grup.

## 🚀 Setup

```bash
# Clone repo
git clone https://github.com/yourusername/kudeta-web-bot.git
cd kudeta-web-bot

# Install dependencies
npm install

# Setup environment
cp .env.example .env
# Edit .env dengan nomor owner

# Pairing mode (pertama kali)
npm run pair

# Atau scan QR (auto)
npm start
